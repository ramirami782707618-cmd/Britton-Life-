# BRITTON LIFE Store Template
واجهة متجر عربية RTL مستوحاة من الصورة المرجعية. تتضمن بحثاً وتصنيفات وفلاتر وسلة تحفظ محلياً وبدء طلب عبر واتساب.

## النشر
ارفع `index.html` و`style.css` و`app.js` إلى جذر مستودع GitHub ثم فعّل GitHub Pages من Settings → Pages.

## قبل النشر
1. افتح `app.js` وابحث عن `let phone="966500000000"` واستبدله برقم واتسابك بالصيغة الدولية دون + أو مسافات.
2. عدّل مصفوفة `products` في `app.js` بأسماء وأسعار وصور المنتجات الحقيقية.
3. الصور الحالية روابط خارجية تجريبية وقد تحتاج استبدالها بصور منتجاتك.
4. نموذج البريد الإلكتروني تجريبي ولا يحفظ العناوين.

## ملاحظات
هذه واجهة Front-end فقط؛ لا توجد بوابة دفع فعلية أو قاعدة بيانات أو تسجيل دخول أو لوحة إدارة متصلة. السلة محفوظة في متصفح الزائر عبر localStorage. الأسعار والمنتجات تجريبية، فحدّثها قبل إطلاق المتجر.
